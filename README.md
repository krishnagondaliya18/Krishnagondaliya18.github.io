# Krishna Gondaliya — Portfolio Website

A software developer portfolio built with OpenAI ChatGPT's design system, featuring light and dark themes, silky smooth typography (`Inter` + `JetBrains Mono`), and high-performance interactive features.

## ✨ Key Features
- **ChatGPT Theme Engine**: Fully responsive dark mode (`#212121`) and clean white mode (`#ffffff`) with persistent `localStorage` support and smooth Sun/Moon icon toggle.
- **ChatGPT Typography & Feel**: Clean font rendering using Google Font `Inter` with optical sizing and `JetBrains Mono` for code & badges.
- **Featured Projects**:
  - **EventHub System**: Event management & online ticketing system with automated workflows (Node.js, MongoDB, Angular, CSS, JavaScript)
  - **KeyStore**: Decoupled microservices architecture with deep-learning visual search & vector database (Python FastAPI, Spring Boot, VectorDB, REST APIs, PostgreSQL)
  - **RealEstate Vault**: Scalable real estate and room-booking platform with dynamic search (Java, Spring Boot, JWT, React, RBAC, JavaScript)
  - **LangPulse AI**: Multi-tenant AI workflow platform with multi-agent orchestration (Java Spring Boot, Python FastAPI, React.js, LangChain, CrewAI, LangGraph)
  - **SmartDoc AI**: Document-based question-answering system with LangChain & RAG (React.js, Python FastAPI, LangChain, RAG, FAISS, LLM, MongoDB)
- **Recruiter Utilities**:
  - 1-Click "Copy Email" button with toast confirmation.
  - Quick action buttons for Live Demo, GitHub, and LinkedIn.
  - Top scroll progress bar indicator.
